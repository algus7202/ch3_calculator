# Streamlit 정수 계산기 (Simple Streamlit Calculator)

Streamlit을 활용하여 구현한 간단한 정수 계산기 웹 애플리케이션입니다.

## 주요 기능
- 첫 번째 정수, 연산자(+, -, *, /), 두 번째 정수를 입력받아 사칙연산 수행
- 정수 외 입력값 처리 예외 메시지 출력
- 지원하지 않는 연산자 입력 시 오류 메시지 출력
- 0으로 나누기 예외 처리

## 실행 방법

### 1. 필수가요 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. Streamlit 앱 실행
```bash
streamlit run calculator.py
```
